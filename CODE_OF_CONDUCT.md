# Code of conduct

Syscura follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep criticism about the work, not the person. Harassment of any kind is not tolerated.

Problems can be reported privately to the maintainer through GitHub ([@hiibrarahmad](https://github.com/hiibrarahmad)). Reports are handled confidentially.
